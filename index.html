What you'll see when installing

Massif isn't on Google Play, so Android asks a few questions on the way in. None of them mean something is wrong.

  1. Chrome may say the file is not commonly downloaded. Massif is new and few people have it yet. Tap Download anyway.
  2. Android asks permission to install apps from Chrome. That's a one-time browser setting, not a permission Massif keeps.
  3. Play Protect scans the file and notes it hasn't seen this app before. Let it scan — it takes a few seconds.
